# Spa Card pour Home Assistant

Carte personnalisée pour gérer votre spa (LayZSpa) via Home Assistant.

## Installation
1. Copiez les fichiers `spa-card.js`, `spa-editor.js` et `spa-styles.js` dans votre dossier `/config/www/spa-card/`.
2. Ajoutez `/local/spa-card/spa-card.js` dans vos ressources de tableau de bord.

## Fonctionnalités
- Gestion de la chimie (pH, ORP, TDS, Sel).
- Éditeur visuel intégré pour configurer vos entités.
- Architecture modulaire.
